# Come Eat Atlas 来吃饭

How parents around the world say sorry without saying it: cut fruit, "come eat", "did you eat?", or silence until it blows over.

- **`apology-map.html`** is an interactive world map with 21 places. Each one has a gesture, a phrase in its own script, an evidence rating and linked sources. Open it in any browser; it's a single self-contained file.
- **`come-eat-mockup.mp4`** is a 3.2-second vertical (9:16, 1080×1920) teaser of the map.

## How to read the evidence bars

| Bars | Meaning |
| --- | --- |
| 3 | Backed by peer-reviewed research |
| 2 | Several independent accounts, or one study |
| 1 | One or two first-hand accounts |

Grey countries mean no reliable source was found, not that parents there never apologize.

Research compiled October 2026. Map data: Natural Earth via [world-atlas](https://github.com/topojson/world-atlas).
